# DRiShti-AI Studio

A modern, dynamic web application for **Explainable Diabetic Retinopathy Screening & Groq-Powered Clinical Assistance**, designed to run directly in VS Code on Windows, macOS, or Linux.

## Run in VS Code
1. Open `C:\Users\ARJUN\Desktop\healthcare\DRiShti-AI-Studio` in VS Code (**File → Open Folder...**).
2. If using a virtual environment (`venv`), install Flask once:
   ```powershell
   python -m pip install -r requirements.txt
   ```
3. Press **`F5`** (uses `.vscode/launch.json`) or run in the VS Code terminal:
   ```powershell
   python server.py
   ```
4. Open **`http://127.0.0.1:5000`** in your browser.
